# ThreeJS 官网文档学习笔记

## 一、快速开始

- 最开始的时候优先按照Demo代码实现，后续再加上自己的想法

### Start

**【目标】** 聚焦于最核心的几个组件的创建、组装和显示，让用户能快速看到效果，建立初步认知。帮助开发者从零开始，在浏览器中构建并运行起第一个 3D 场景。

- 三大核心组件：创建一个基本的 3D 场景，主要需要三个东西：场景（Scene）、相机（Camera） 和 渲染器（Renderer）。
- 场景（Scene）：这是 3D 世界的容器或舞台。你创建的所有物体（如立方体、球体）、光源等都需要添加到场景中，才能被渲染出来。
- 相机（Camera）：相当于观众的“眼睛”或一台“摄像机”。它定义了我们从哪个角度、以什么视野来观看这个 3D 舞台。最常见的是透视相机（PerspectiveCamera），它能模拟人眼看到的近大远小的效果。
- 渲染器（Renderer）：相当于“绘图引擎”。它的工作是获取场景和相机的信息，将 3D 画面计算并绘制到网页的一个 HTML canvas 元素上。
- 基本几何体与材质：为了在场景中看到东西，需要创建物体。一个物体通常由几何体（Geometry，决定形状） 和材质（Material，决定外观，如颜色） 组合而成。基础部分通常会用一个简单- 的立方体（BoxGeometry）和基础网格材质（MeshBasicMaterial）来演示。
- 动画循环：为了让画面动起来（如旋转立方体），需要使用 requestAnimationFrame 函数创建一个循环，在这个循环里不断更新物体状态并重新渲染画面。

### 响应式设计

1. 核心问题：当浏览器窗口大小改变时，3D画布（Canvas）会被拉伸或留白，导致画面变形或显示不全。
2. 解决方案：监听窗口的 resize 事件。
3. 关键步骤：
  - 更新渲染器尺寸：renderer.setSize(newWidth, newHeight)
  - 更新相机参数：对于PerspectiveCamera，需要更新其 aspect（纵横比）并调用 camera.updateProjectionMatrix()。
  - 可选：处理像素比（window.devicePixelRatio）以适应高清屏。

## 二、基础

### 图元

&nbsp;&nbsp;&nbsp;&nbsp;【图元】部分主要介绍Three.js内置的基础几何体形状。这些图元是构建3D物体的最基本"积木块"，可以直接使用，不需要从零开始定义顶点数据。学习这部分就是学习如何创建和配置各种标准3D形状。

**核心知识点总结**
  1. 什么是图元：预定义好的基础几何形状，如立方体、球体、圆柱体等
  2. 图元创建接口：所有图元都通过对应的构造函数创建，如new THREE.BoxGeometry()
  3. 参数配置：每个图元都有特定的参数控制其外观（尺寸、分段数等）
  4. 几何体与材质分离：图元只定义形状，需要配合材质才能显示
  5. 常用图元类型：立方体、球体、圆柱体、圆环、平面等基础形状
   
**可掌握知识/技能**
  1. 创建各种基础3D形状：能够使用代码生成常见的几何体
  2. 理解几何体参数：知道不同参数如何影响几何体的外观和细节
  3. 组合图元创建复杂物体：理解如何用多个简单图元组合成复杂模型
  4. 控制几何体细节程度：通过分段数参数平衡视觉效果和性能

**关键要点**
  1. 分段数的重要性：分段数（segments）决定了几何体的精细程度，分段数越高越光滑但也越消耗性能
  2. 参数顺序：不同图元的参数顺序不同，需要查阅文档或类型提示
  3. 坐标系理解：不同图元的默认朝向和轴心点可能不同
  4. 性能考虑：使用合理的最小分段数，避免不必要的性能消耗
  5. 可视化调试：创建图元时可以先使用简单材质（如MeshBasicMaterial）快速查看效果

### 场景图
&nbsp;&nbsp;&nbsp;&nbsp;"场景图"部分讲解的是Three.js中对象组织和管理的方式。它就像一个树形结构或家谱图，所有的物体、灯光、相机等都按照父子关系组织在一起。理解场景图是掌握如何有效控制复杂3D场景的关键，比如让一组物体一起移动、旋转，或创建层次结构。使用太阳系模型作为示例，展示如何构建一个复杂的场景图。

**核心知识点**
- **树形结构**：Three.js中的场景是一个树（scene graph），场景（Scene）是根节点，所有物体都是它的子节点。
- **父子关系**：一个物体（Object3D）可以包含多个子物体。子物体会继承父物体的位置、旋转和缩放变换。
- **局部坐标系与世界坐标系**：
  - **局部坐标**：每个物体以自己的中心点为原点。
  - **世界坐标**：物体在最终场景中的绝对位置。
  - 子物体的世界坐标 = 父物体的世界变换 × 子物体的局部变换。
- **scene.add(object) 与 object.add(child)**：这是构建场景图的基本操作，用于将物体添加到场景或另一个物体下。
- **Object3D 是核心基类**：场景（Scene）、网格（Mesh）、相机（Camera）等都继承自Object3D，因此都具备操作场景图的能力（如add、remove、position、rotation）。

**可掌握知识/技能**
  1. **理解场景的层次结构**：明白3D场景中物体是如何关联的。
  2. **创建对象层级**：将多个物体分组，使它们能作为一个整体被操控（例如，创建一辆汽车，让轮子作为车身的子物体，车身移动时轮子自动跟随）。
  3. **管理复杂场景**：使用场景图清晰地组织大量物体，而不是散乱地管理。
  4. **进行坐标转换**：理解并计算物体在局部和世界空间中的位置。
  5. **遍历场景图**：查找或操作场景中的特定物体。

**关键要点**
  1. **变换的继承是核心**：这是场景图最重要的特性。对父物体进行移动（position）、旋转（rotation）或缩放（scale），子物体会连带受影响。这大大简化了复杂动画和布局。
  2. **添加顺序有时很重要**：虽然不影响结构，但可能影响渲染顺序（如透明度渲染）。
  3. **一个物体只能有一个父级**：不能同时存在于两个父物体下。如果要改变父级，需要先remove，再add到新父级。
  4. **注意性能**：非常深的场景图层次（比如几十层）可能会对性能有微小影响，但通常不是主要瓶颈。
  5. **调试小技巧**：可以使用 scene.traverse() 函数遍历所有物体来检查场景图结构。

### 材质

  - 将纹理与材质结合

**关键要点**
  - 选择合适的材质类型
  - 性能考虑：复杂材质更耗资源
  - 光照与材质的配合
  - 透明材质的渲染顺序问题

### 纹理
&nbsp;&nbsp;&nbsp;&nbsp;这部分教您如何为3D物体“贴图”。让一个立方体从单一颜色变成有木纹、砖墙、皮肤等细节的物体，就是通过纹理实现的。它从最简单的加载一张图片开始，逐步讲解如何应用、控制纹理的重复和偏移，最后介绍更高级的立方体纹理（如创建天空和反射效果）。

**核心知识点**
1. 加载纹理：使用 THREE.TextureLoader().load(图片地址) 来加载图片文件。
2. 应用纹理：将加载好的纹理对象，作为参数传给材质的 map 属性（例如：{ map: texture }）。
3. 纹理坐标（UV）：每个3D模型表面都有一套2D坐标（UV），决定了图片如何“包裹”在模型上。这通常在3D建模软件中完成。
4. 控制纹理：可以通过纹理对象的 repeat（重复次数）、offset（偏移量）、wrapS/wrapT（环绕模式）等属性，调整图片在模型表面的铺贴方式。
5. 立方体纹理：由6张图片组成一个立方体的六个面，主要用于天空盒和环境反射。使用 THREE.CubeTextureLoader().load() 加载，并赋给材质的 envMap 属性。

**可掌握知识/技能**
1. 掌握为任何几何体添加图片贴图的方法。
2. 能创建出沉浸式的3D场景背景（天空盒）。
3. 能为金属、玻璃等物体添加逼真的环境反射效果。
4. 能通过重复平铺小图片来制作大表面（如草地、地板），节省资源。

**关键要点**
1. 图片需放到服务器：因浏览器安全限制，不能直接用本地文件地址（file://），需要在本地运行一个Web服务器，或使用在线地址。
2. 加载是异步的：图片加载需要时间，可能在加载完成前物体已被渲染成黑色。复杂的项目需要考虑加载管理。
3. 纹理尺寸是2的幂：如128，256，512，1024等。使用非2的幂尺寸的图片在某些设备上可能导致显示问题或性能下降。
4. 性能与内存：纹理（尤其是高清图）会占用大量显存。手机等设备需要注意纹理尺寸和数量。

### 灯光
&nbsp;&nbsp;&nbsp;&nbsp;这部分介绍了几种模拟现实世界光线效果的方法（如自然光、聚光灯等），并解释了如何将这些光源添加到场景中，使3D物体具备明暗、立体感和颜色，从而告别单调的平面感。

**核心知识点**
1. 光照的意义：没有光源，物体颜色就是材质本身的“平涂”。有光，物体才有明暗、立体感和环境氛围。
2. 光的类型：three.js提供多种模拟现实的光源。
  - 环境光：像阴天的天空光，均匀照亮所有物体，能“柔化”阴影，但自身不产生阴影。
  - 半球光: 是用来模拟天空和地面同时产生漫反射的环境光，能让室外场景的明暗过渡更加自然。
  - 方向光: 是模拟无限远处光源（如太阳）的平行光线，能为场景提供清晰的方向性照明和长长的投影。
  - 点光源：像灯泡，从一个点向所有方向均匀发光。
  - 聚光灯：像手电筒或舞台追光，从一点沿一个锥形方向照射，有中心亮、边缘暗的效果。
  - 矩形区域光: 是模拟从一个矩形平面均匀发出的柔和光源（如明亮的窗户或灯箱），能产生平滑过渡的阴影和光照，适合营造真实的环境照明。
3. 基本使用流程：创建光源对象 → 设置属性（颜色、强度、位置、方向等） → 将其添加到场景中。
4. 相互作用：光照效果与物体的“材质”属性紧密相关。例如，反光强的材质在光照下更亮。

**可掌握知识/技能**
1. 理解原理：明白为什么3D场景需要打光，以及不同光源类型的基础原理。
2. 实践能力：学会创建和设置环境光、点光源、平行光、聚光灯，并将其加入到场景。
3. 组合应用：能够组合使用多种光源（例如：环境光 + 平行光）来模拟更真实、有层次的光照效果。

**注意事项**
1. 光与材质：光源本身不会让物体变黑或变亮，最终效果取决于光源+材质的组合。例如，深色材质在强光下也不会很亮。
2. 性能考量：不同类型的光源对性能消耗不同。平行光和环境光计算开销较小，而聚光灯和点光源（特别是需要计算阴影时）开销较大。初期为学习可以随意添加，但开发复杂应用时需注意优化。
3. 阴影非自带：默认情况下，光源不产生阴影。要让物体投下阴影，需要专门为光源和物体开启阴影计算，这是一项独立且相对复杂的设置。

### 摄像头
&nbsp;&nbsp;&nbsp;&nbsp;摄像机部分介绍了如何创建和控制观察3D场景的“眼睛”，决定了用户看到的内容范围、角度和透视效果，是构建3D应用的基础。

**核心知识点**
1. **摄像机作用**：摄像机是观察3D场景的“窗口”，决定用户能看到什么。
2. **摄像机类型**：主要有两种：
  - **透视相机**：模拟人眼视角，有近大远小的透视效果，适合大多数3D场景。
  - **正交相机**：无透视变形，物体大小与距离无关，适合建筑图纸、2.5D游戏等。
3. **相机参数**：通过设置参数控制观察范围：
  - **透视相机**：视野角、宽高比、近裁剪面、远裁剪面
  - **正交相机**：左、右、上、下、近、远边界
4. **相机控制**：可以通过改变相机位置、朝向、参数来调整视角。

**可掌握知识/技能**
1. **会创建透视相机和正交相机**
2. **能够设置相机的基本参数**
3. **掌握将相机添加到场景并调整位置的方法**
4. **理解两种相机的适用场景**

**注意事项**
1. **近裁剪面不能为0**：必须设置为大于0的值，否则什么都看不到
2. **参数合理性**：远近裁剪面的设置要合适，太近会看不到近处物体，太远会影响性能
3. **相机位置**：相机默认位置在原点(0,0,0)，需要调整位置才能看到场景内容
4. **相机朝向**：相机默认看向Z轴负方向（屏幕内部）
5. **宽高比**：通常设为画布的实际宽高比例

#### 阴影
&nbsp;&nbsp;&nbsp;&nbsp;阴影部分讲解了如何在3D场景中为物体添加投影效果，让光照关系更真实。这涉及到光源、物体、接收面三方的协同设置。

**核心知识点**
1. 阴影需要三方协作：
  - 能投射阴影的光源
  - 能投射阴影的物体
  - 能接收阴影的表面
2. 光源支持：不是所有光源都能产生阴影。通常聚光灯和平行光支持阴影，点光源和环境光不支持。
3. 渲染器设置：需要在渲染器中启用阴影功能。
4. 阴影类型：提供不同类型的阴影算法（如基本阴影、软阴影等），质量和性能不同。
5. 性能消耗：阴影计算比较耗费性能，需要合理设置参数。

**可掌握知识/技能**
1. 理解Three.js中阴影系统的工作原理
2. 能够创建能投射阴影的光源
3. 会设置物体投射和接收阴影
4. 掌握渲染器中的阴影基本配置
5. 能调整阴影质量和性能的平衡

**注意事项**
1. 所有都需要设置：光源、物体、渲染器都要正确设置才能看到阴影
2. 光源支持有限：使用前确认光源类型是否支持阴影
3. 阴影范围设置：要为平行光或聚光灯设置合适的阴影范围（shadow.camera）
4. 性能优化：阴影贴图分辨率（shadow.mapSize）越大质量越好，但性能越差
5. 物体材质：有些材质可能不支持阴影或需要特殊设置
6. 阴影边缘：适当设置阴影模糊（shadow.blur）可以让阴影边缘更柔和自然

### PBR 材质
  1、物理渲染材质（PBR）是一种基于物理的渲染材质模型，用于模拟真实世界中的光照和材质行为。
  2、PBR 材质使用粗糙度（Roughness）和金属度（Metallic）等属性来描述材质的表面特征，而不是传统的颜色和透明度。
  3、PBR 材质在 Three.js 中通过 MeshStandardMaterial 类实现。
