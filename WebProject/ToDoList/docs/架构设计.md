### 各层职责

#### 1. 表现层 (Presentation Layer)

**职责**:
- 接收 HTTP 请求
- 参数验证和转换
- 调用业务层服务
- 返回响应结果

**实现**:
- Controllers: 处理 HTTP 请求和响应
- DTOs: 定义请求和响应的数据结构
- 装饰器: 路由、参数验证、权限控制

**示例**:
```typescript
@Controller('todos')
export class TodosController {
  constructor(private readonly todosService: TodosService) {}

  @Post()
  create(@Body() createTodoDto: CreateTodoDto) {
    return this.todosService.create(createTodoDto);
  }
}
```

#### 2. 业务层 (Business Layer)

**职责**:
- 实现业务逻辑
- 协调多个数据访问操作
- 事务管理
- 业务规则验证

**实现**:
- Services: 封装业务逻辑
- 业务规则: 验证和约束
- 事务: 保证数据一致性

**示例**:
```typescript
@Injectable()
export class TodosService {
  constructor(
    @InjectRepository(Todo)
    private readonly todoRepository: Repository<Todo>,
  ) {}

  async create(userId: number, createTodoDto: CreateTodoDto): Promise<Todo> {
    const todo = this.todoRepository.create({
      ...createTodoDto,
      userId,
    });
    return this.todoRepository.save(todo);
  }
}
```

#### 3. 数据访问层 (Data Access Layer)

**职责**:
- 封装数据库操作
- 提供 CRUD 接口
- 管理实体关系
- 优化查询性能

**实现**:
- Repositories: 数据访问接口
- Entities: 数据模型映射
- Query Builders: 复杂查询构建

**示例**:
```typescript
@Entity()
export class Todo {
  @PrimaryGeneratedColumn()
  id!: number;

  @Column()
  title!: string;

  @ManyToOne(() => User)
  user!: User;
}
```

#### 4. 基础设施层 (Infrastructure Layer)

**职责**:
- 提供基础服务
- 管理外部依赖
- 配置管理
- 日志和监控

**实现**:
- Database Module: 数据库连接
- Config Module: 配置管理
- Logger Module: 日志服务
- Cache Module: 缓存服务

### 安全措施

#### 1. 密码安全

- 使用 bcrypt 加密存储密码
- 密码哈希强度: cost factor = 10
- 密码复杂度要求: 至少 6 个字符
- 密码不在日志中记录

#### 2. JWT 安全

- 使用强随机密钥生成 JWT
- Token 过期时间: 24 小时
- Token 存储: HttpOnly Cookie 或 LocalStorage
- Token 刷新机制: 可选实现

#### 3. 输入验证

- 使用 class-validator 进行参数验证
- 所有输入都经过验证管道
- 防止 SQL 注入和 XSS 攻击
- 限制请求体大小

#### 4. 限流保护

- 基于 IP 和用户的限流
- 默认限制: 100 请求/分钟
- 超过限制返回 429 状态码
- 使用 ThrottlerGuard 实现

#### 5. CORS 配置

- 配置允许的域名白名单
- 限制 HTTP 方法
- 设置允许的请求头
- 支持预检请求

## 性能优化

### 优化策略

#### 1. 数据库优化

**索引优化**:
- 为常用查询字段创建索引
- 使用复合索引优化多条件查询
- 定期分析索引使用情况

**查询优化**:

#### 2. 熔断机制

```typescript
@Injectable()
export class CircuitBreakerInterceptor implements NestInterceptor {
  private failureCount = 0;
  private lastFailureTime: Date;
  private readonly threshold = 5;
  private readonly timeout = 60000; // 1 minute

  intercept(context: ExecutionContext, next: CallHandler): Observable<any> {
    if (this.isOpen()) {
      return throwError(() => new ServiceUnavailableException());
    }

    return next.handle().pipe(
      catchError((error) => {
        this.recordFailure();
        return throwError(() => error);
      }),
      tap(() => this.reset()),
    );
  }

  private isOpen(): boolean {
    return (
      this.failureCount >= this.threshold &&
      Date.now() - this.lastFailureTime.getTime() < this.timeout
    );
  }

  private recordFailure(): void {
    this.failureCount++;
    this.lastFailureTime = new Date();
  }

  private reset(): void {
    this.failureCount = 0;
  }
}
```

#### 3. 降级策略

```typescript

export class FallbackInterceptor implements NestInterceptor {

      }),
```
